# Ikibazo cya kabiri ku magambo avanze — Kinyarwanda / Icyongereza

Murakoze cyane ku gisubizo cya mbere. Ibibazo bikurikira ni bibiri gusa.

---

## 1. Uko ijambo ry'icyongereza rikoreshwa mu nteruro y'ikinyarwanda

> Ndashaka kumenya ijambo ry'icyongereza iyo rishyizwe mu nteruro
> y'ikinyarwanda, si ijambo ry'ikinyarwanda.
>
> Urugero: **"Mfite chest pain ikabije"** — kuki ari *ikabije* aho kuba
> *cyabije* cyangwa *bikabije*?

Kuri buri jambo hano hepfo: **iyo urikoresheje mu nteruro y'ikinyarwanda,
uvuga ute? Andika interuro nto irimo iryo jambo.**

| # | ijambo | interuro yawe |
|---|---|---|
| 1 | fever | |
| 2 | chest pain | |
| 3 | test | |
| 4 | doctor | |
| 5 | nurse | |
| 6 | tablets | |
| 7 | X-ray | |
| 8 | pressure | |
| 9 | sugar | |
| 10 | scan | |

**Impamvu tubaza:** twanditse ko *chest pain* ari "Class 9 (i-)". Interuro
yawe ni yo izatwereka niba ari byo — kandi niba ari uko, izatwereka uko
inyuguti z'imbere zihinduka ku zindi ngingo z'interuro. Ntidushobora
kubyibwiriza.

**Ku magambo abiri (test, tablets):** wanditse uburyo bubiri.

- **test** — Class 9 (i-) cyangwa Class 7 (igi-)?
- **tablets** — *Ibinini* (Class 8) cyangwa *Komprime* (Class 9)?

Ibi si ubwoko bumwe bwanditse ukundi; ni **amasezerano abiri atandukanye**,
kandi interuro ihinduka. Tubaze kuri buri kimwe: ni ikihe abantu bakoresha,
cyangwa byombi bikoreshwa mu buryo butandukanye?

---

## 2. Ni iryahe rikoreshwa koko?

Kuri **fever**, **doctor**, **nurse** wanditse ko ijambo ry'ikinyarwanda ari
ryo rikoreshwa cyane:

| ijambo | ry'ikinyarwanda | ikibazo |
|---|---|---|
| fever | Umuriro | Ese abantu bavuga **"fever"** cyangwa **"umuriro"**? |
| doctor | Muganga | Ese bavuga **"doctor"** cyangwa **"muganga"**? |
| nurse | Umuforomo | Ese bavuga **"nurse"** cyangwa **"umuforomo"**? |

Niba ijambo ry'ikinyarwanda ari ryo rikoreshwa hafi ya buri gihe,
**ntituzarikoresha nk'ijambo rivanze** — tuzakoresha iry'ikinyarwanda mu
nteruro isanzwe. Ntabwo ari ikosa; ni ukumenya ukuri.

---

## Icyo tutazakora

Ntituzandika izo nteruro twebwe. Niyo mpamvu tubaza.
